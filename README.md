# Orbit Shifting

Orbit Shifting is Shanmukha Agritec's farmer programme in Telangana. It has three interfaces on one backend:

- **Farmer app** (Flutter, Telugu first): OTP sign-up, crop advice, FA visits, call-backs, advisories with a Listen button.
- **Field Assistant (FA) app** (Flutter, offline first): enrol farmers, log visits in villages with no signal, sync later.
- **Head Office (HO) portal** (React): manage FAs, villages, masters, advisories, farmers and the audit trail.

The backend is a Go modular monolith on PostgreSQL (with PostGIS) and Redis. Money features (Premium, cashback,
payouts) come in Phase 2.

### Backend in a bit more detail

Done:

- **Modules:** identity, geo, farmers, masters, visits, messaging, sync and audit, each with its own spec, SQL
  (sqlc) and tests.
- **Auth:** OTP for farmers, password + PIN for FAs, password + TOTP for HO users, plus device binding,
  refresh tokens and forced password change.
- **FA offline sync:** a snapshot goes down (with ETag), commands come up in batches. Commands are idempotent, and
  bad ones are rejected or dead-lettered.
- **Business rules:** consent OTP proof on enrolment, maker-checker on advisories and advice rules, quiet hours,
  and no competitor brands (advice is a Shanmukha SKU or "salt only").
- **Background work:** worker jobs on River (Postgres-backed) for messaging, alerts and retention.
- **Checks:** `make check` passes 25 test packages. `tools/smoke_test.py` runs 93 checks end to end against
  a running API.

Still to do (full list in [backend/implementation-plan.md](backend/implementation-plan.md)):

- Real adapters: SMS with DLT template IDs, FCM push, S3 storage, and later WhatsApp.
- Calendar and stage reminders, the weather feed, CSV import/export, and territory hand-over in one call.
- Deployment to AWS (waits on `infra/`).
- Phase 2 money features, then Phase 3 growth features.

## Running the backend locally

You need Docker, Go 1.27 and sqlc 1.31. Install steps are in [backend/README.md](backend/README.md).

```sh
make dev-up               # Postgres + PostGIS and Redis; creates backend/.env from .env.example
make migrate              # schema + River tables
make backend-seed         # dev data; prints the logins
make backend-run-api      # API on :8080
make backend-run-worker   # worker, in another terminal (health on :8081)

python3 tools/smoke_test.py   # optional: full client flow against the running API
```

Other useful targets: `make backend-check` (stale generated code, gofmt, vet, tests), `make backend-specs`
(regenerate `ENDPOINTS.md` and the client bundles), `make backend-image` (Docker image), `make backend-help`.

## Running the Farmer and FA apps locally

You need the Flutter version in `mobile/.fvmrc`, an Android device or emulator, and melos
(`dart pub global activate melos 8.10.0`). Both apps run on mock data, so no backend is needed. Details, mock logins
and the dev menu are in [mobile/README.md](mobile/README.md).

```sh
cd mobile && flutter pub get && cd ..
make farmer-run      # Farmer app, dev flavour, Android only for now
make fa-run          # FA app, dev flavour (mock login FA-KDP-014 / orbit2026)
make tokens          # after changing design/tokens/*.json
make i18n            # after changing i18n/*.json
make mobile-check    # regenerate, analyze, all mobile tests
```

## How we work

- **Contract first.** Change the spec in `contracts/openapi/`, regenerate, then write code. Generated code is
  committed and CI fails if it is stale. Don't break `/v1/farmer` or `/v1/fa`, because old app versions stay on
  phones for months.
- **No secrets in the repo.** Dev uses `backend/.env` (gitignored) and log-only SMS and push. Staging and prod
  will read secrets from AWS Secrets Manager.
- **Telugu first** on every farmer screen. Strings come from `i18n/`, colours from `design/`.
- **Redis is only a cache.** If Redis is down, things get slower but nothing breaks.
- Backend coding rules are in [backend/docs/CONVENTIONS.md](backend/docs/CONVENTIONS.md).
- The wireframe HTML files are large and stay out of the repo. Text copies are in `docs/source/`.
